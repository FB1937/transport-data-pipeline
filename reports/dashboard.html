처음 방문한 분을 위한 안내

이 대시보드는 무엇을 보여주나요?

국토교통부의 2025년 대중교통 데이터를 바탕으로 부산의 어느 지역에서, 어떤 교통수단이, 언제 많이 이용되었는지 보여줍니다.

모든 이용량은 건수 기준이며, 사람 수와는 다른 지표입니다. 이용인원 자료는 별도로 표시해 두 지표를 혼동하지 않도록 했습니다.

화면 이용 방법

Districts: 부산 구·군별 이용량과 이용인원 순위를 비교합니다.

Transport: 시내버스·마을버스·도시철도 등 교통수단별 비중을 확인합니다.

Monthly: 월별 변화와 시간대별 이용 패턴을 살펴봅니다.

Explorer: 구·군과 교통수단을 선택해 원하는 조건만 자세히 봅니다.

데이터 범위

기간: 2025년 1월~12월

지역: 부산 16개 구·군

출처: 국토교통부 시군구별 대중교통 이용인원수·교통수단별 이용량·시간대별 이용량

데이터를 믿을 수 있도록 한 점

분석 전에 빈 값, 중복 행, 음수 이용량, 잘못된 시간대 값을 점검했습니다.

정제된 CSV와 SQLite 데이터베이스의 행 수를 비교하고, Python과 SQL로 계산한 결과도 대조했습니다.

분석 시 참고할 점

이용량과 이용인원은 서로 다른 원천 자료에서 계산된 값이므로 직접 같은 의미로 비교하면 안 됩니다.

이 대시보드는 2025년 자료를 기준으로 하며, 노선·환승·요일별 이용 목적까지 설명하지는 않습니다.

재현하고 싶은 분께

Python이 설치된 환경에서 프로젝트 폴더를 연 뒤 아래 명령을 실행하면 원천 데이터 점검부터 대시보드 생성까지 다시 수행합니다.

python -m src.run_pipeline

완료 후 생성되는 결과는 reports/dashboard.html, 그래프는 reports/figures, 데이터베이스는 data/processed/transport_usage.sqlite, 실행 기록은 logs/pipeline.log에서 확인할 수 있습니다.

Data source: 국토교통부 시군구별 대중교통 이용 데이터  ·  Python · SQLite · Matplotlib
