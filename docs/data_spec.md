# 데이터 사양 메모

## 출처와 수집 파일

- 출처: [공공데이터포털 - 시군구별 교통수단별 이용량](https://www.data.go.kr/data/15162136/fileData.do)
- 로컬 원본: `data/raw/transport_usage.csv`
- 추가 원본: `data/raw/국토교통부_시군구별 대중교통이용인원수_20251231.csv`
- 추가 원본: `data/raw/국토교통부_시군구별 시간대별 대중교통이용인원수_20251231.csv`
- 원본 보존 원칙: 원본은 수정하지 않고 정제 결과를 `data/processed/`에 별도로 저장한다.
- 라이선스와 이용 조건: 위 출처 페이지의 최신 이용 조건을 확인해야 한다.

## 실제 파일 확인 결과

- 관측 기간: 2025-01-01 ~ 2025-12-31
- 행 수: 315,505
- 행 단위: 운행일자·시도·시군구·교통수단별 이용량 집계
- 인코딩: CP949
- 결측치: 0건
- 완전 중복: 0건
- 음수 이용량: 없음
- 수집 방식: 공공데이터포털에서 CSV를 내려받아 `data/raw/`에 보존
- 지도 경계: `data/geo/busan_sgg.geojson` (부산 구·군 경계, 2025년 기준)
- 추가 원천: 시군구별 이용인원수 및 시군구별 시간대별 이용량 CSV

## 컬럼

| 원본 컬럼 | 정제 컬럼 | 의미 |
|---|---|---|
| 운행일자 | operation_date | 관측 운행일 |
| 시도코드(법정동) | sido_code | 시도 식별 코드 |
| 시도명 | sido_name | 시도명 |
| 시군구코드(법정동) | sigungu_code | 시군구 식별 코드 |
| 시군구명 | sigungu_name | 시군구명 |
| 교통수단명 | transport_type | 교통수단 분류 |
| 이용량 | usage_count | 제공 데이터의 이용량 집계값 |

추가 데이터셋은 다음과 같습니다.

| 원천 파일 | 정제 테이블/파일 | 주요 컬럼 |
|---|---|---|
| 시군구별 대중교통이용인원수 | `transport_person` | `person_count` |
| 시군구별 시간대별 대중교통이용인원수 | `transport_hourly` | `hour`, `usage_count` |

추가 파일 확인 결과 이용인원 데이터는 96,366행, 시간대 데이터는 1,843,188행이며,
시간대는 00~23시 범위로 정제한다.

## 해석 범위

현재 파일에는 일자·지역·교통수단 수준의 집계만 있으므로 정류장, 개별 승객,
시간대 분석은 수행하지 않는다. 이용량의 단위와 집계 기준은 출처 페이지의 설명을
함께 확인해야 하며, 이 프로젝트는 원본 값을 임의로 추정하거나 보정하지 않는다.
